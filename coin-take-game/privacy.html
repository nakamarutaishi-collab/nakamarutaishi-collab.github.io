プライバシーポリシー

制定日：2026年11月10日

対象アプリと運営者

本ポリシーは、iPhone向けアプリ「硬貨取ゲーム」（以下「本アプリ」）に適用されます。運営者は丸尾 稜です。

本アプリが扱う情報

本アプリは、アカウント登録やオンライン対戦を提供しません。対戦中の盤面、手番、得点は端末上のメモリで処理し、運営者のサーバーには送信・保存しません。アプリを終了すると対戦状態は保持されません。

広告とGoogle Mobile Ads SDK

本アプリはGoogle AdMobのGoogle Mobile Ads SDKと、広告同意管理のGoogle User Messaging Platform（UMP）を利用します。広告のリクエスト前に同意情報を確認し、広告をリクエストできる場合にSDKを初期化します。

Google Mobile Ads SDKは、広告の配信・測定、不正防止、分析、SDKの診断や性能改善などのため、端末識別子（広告IDなど）、IPアドレス、IPアドレスから推定されるおおよその位置情報、広告情報、広告表示やアプリ上の操作に関する情報、診断・性能情報などを収集または利用する場合があります。実際の処理は地域、同意内容、端末設定、SDKの仕様によって異なります。運営者は対戦結果や硬貨の選択を広告SDKへ渡しません。

詳しくはGoogle Mobile Ads SDKのデータ開示およびGoogleプライバシーポリシーをご確認ください。

保存期間と削除

運営者は対戦履歴をサーバーに保存しません。広告関連情報の保持、利用者による広告設定や情報管理については、Googleのポリシーと設定をご確認ください。
